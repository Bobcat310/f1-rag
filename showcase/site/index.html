Personal project

F1 RAG

Ask about 76 years of Formula 1 and get an answer you can check. A keyword router sends each question to SQL filled in by Python, SQL written by a small local model, or search over sentences built from the results tables, and it refuses what the data doesn't hold. It runs on a laptop CPU with no paid APIs.

Results on frozen question sets

For each set, 30 questions were committed after the code and before any run, then scored once. I wrote sets 1 to 4. Sets 5 to 7 were written by a separate agent that saw the data but never the code, and their looser wording is the honest test.

Data: the Kaggle dataset "Formula 1 Complete History (1950–2026)", licensed CC BY 4.0, loaded into DuckDB, cleaned and turned into sentences, with the 2026 season, sprints and pit stops from the Jolpica API. Not affiliated with Formula 1.
